# Architecture & Interface Design Documentation (`telua_flower`)

Thư mục `docs/design/` chứa các tài liệu thiết kế giao diện, kiến trúc hệ thống và đặc tả kỹ thuật:

1. **[FRONTEND_LAYOUT_DESIGN.md](file:///d:/code/telua_flower/docs/design/FRONTEND_LAYOUT_DESIGN.md)**: Thiết kế toàn diện kiến trúc 3 Bố cục giao diện Frontend (Layout Khách hàng Storefront, Layout Thợ cắm hoa Mobile-First `/portal/staff`, và Layout Quản trị Dashboard 2 cột `/portal/admin`), hệ thống Design Tokens màu sắc & typography.
2. **[DYNAMIC_I18N_CONTENT_CMS_DESIGN.md](file:///d:/code/telua_flower/docs/design/DYNAMIC_I18N_CONTENT_CMS_DESIGN.md)**: Thiết kế phân hệ Quản trị Nội dung & Biên dịch Đa ngôn ngữ Động (Dynamic i18n & Content CMS) cho phép Admin/Quản lý chỉnh sửa trực tiếp câu chữ của cả 5 ngôn ngữ (Việt, Anh, Nhật, Hàn, Trung) và nội dung các khối trang lưu vào `config/translations.json`.
3. **[MEMORY_OPTIMIZATION_DESIGN.md](file:///d:/code/telua_flower/docs/design/MEMORY_OPTIMIZATION_DESIGN.md)**: Thiết kế tối ưu hóa bộ nhớ RAM và xử lý dữ liệu lớn (phân trang bắt buộc, phân mảnh file JSON theo tháng, quy trình nén ảnh WebP tự động, đọc ghi stream và LRU cache có giới hạn < 150MB RAM).
4. **[JSON_DATA_SCHEMAS.md](file:///d:/code/telua_flower/docs/design/JSON_DATA_SCHEMAS.md)**: Thiết kế toàn diện cấu trúc dữ liệu lưu trữ JSON (8 tệp JSON: `branches.json`, `users.json`, `price_levels.json`, `products.json`, `orders.json`, `promotions.json`, `wastage_reports.json`, `customers_crm.json`) cùng sơ đồ quan hệ thực thể (ERD).
5. **[OPERATIONAL_EXTENSIONS_DESIGN.md](file:///d:/code/telua_flower/docs/design/OPERATIONAL_EXTENSIONS_DESIGN.md)**: Thiết kế hệ thống Thông báo tự động qua Zalo ZNS / SMS kèm link ảnh hoa thật, phân hệ xuất hóa đơn điện tử VAT cho khách doanh nghiệp (B2B E-Invoice) và mẫu in phiếu giao hàng chuẩn máy in nhiệt K80/A5.
6. **[PRICE_LEVEL_GOVERNANCE_DESIGN.md](file:///d:/code/telua_flower/docs/design/PRICE_LEVEL_GOVERNANCE_DESIGN.md)**: Thiết kế hệ thống Phân tầng mức giá chuẩn (Price Levels) và hàng rào kiểm soát giá sàn/giá trần (Price Guardrails) nhằm ngăn chặn nhân viên set giá chênh lệch quá cao hoặc quá thấp; chỉ Admin/Quản lý mới có quyền thiết lập.
7. **[PROMOTION_CAMPAIGN_DESIGN.md](file:///d:/code/telua_flower/docs/design/PROMOTION_CAMPAIGN_DESIGN.md)**: Thiết kế phân hệ Quản lý Khuyến Mãi (Mã giảm giá Voucher, Banner sự kiện ngày lễ, Thanh thông báo Top Bar) kèm cơ chế Bật/Tắt 1-chạm (ON/OFF Toggle) dành cho Admin và Quản lý.
8. **[PAYMENT_CANCELLATION_RETURN_DESIGN.md](file:///d:/code/telua_flower/docs/design/PAYMENT_CANCELLATION_RETURN_DESIGN.md)**: Thiết kế quy trình thanh toán (VietQR, Visa/Mastercard, COD), chính sách hủy đơn theo 3 mốc thời gian và quy trình đổi trả / đền bù 100% khi hoa bị dập hỏng trong vòng 60 phút.
9. **[PRODUCT_CONTENT_MANAGEMENT_DESIGN.md](file:///d:/code/telua_flower/docs/design/PRODUCT_CONTENT_MANAGEMENT_DESIGN.md)**: Thiết kế phân hệ Product CMS cho phép nhân viên/quản lý thêm, chỉnh sửa giá bán, tải ảnh hoa, cập nhật thành phần hoa, kích thước và mẹo chăm sóc hoa tươi.
10. **[MULTI_BRANCH_INVENTORY_TRACKING.md](file:///d:/code/telua_flower/docs/design/MULTI_BRANCH_INVENTORY_TRACKING.md)**: Thiết kế hệ thống theo dõi tồn kho hoa tươi đa chi nhánh theo thời gian thực (Multi-Branch Real-Time Inventory Matrix), hiển thị trạng thái còn nhiều 🟢 / sắp hết 🟠 / hết hàng 🔴 và tự động điều phối đơn hàng thông minh.
11. **[INVENTORY_MANAGEMENT_DESIGN.md](file:///d:/code/telua_flower/docs/design/INVENTORY_MANAGEMENT_DESIGN.md)**: Thiết kế quy trình nhân viên đăng sản phẩm hoa mới và cập nhật số lượng tồn kho hoa tươi theo ngày (Daily Quota), cơ chế tự động trừ kho và cảnh báo hết hàng trên website.
12. **[AUTHENTICATION_DESIGN.md](file:///d:/code/telua_flower/docs/design/AUTHENTICATION_DESIGN.md)**: Thiết kế kiến trúc **Cổng đăng nhập duy nhất (Single Login Portal)** và cơ chế tự động nhận diện vai trò (Dynamic Role-Based Redirection), cấu trúc JWT Payload, phân tầng bảo vệ Route Guard và API Decorator.
13. **[API_ENDPOINTS.md](file:///d:/code/telua_flower/docs/design/API_ENDPOINTS.md)**: Đặc tả chi tiết toàn bộ các RESTful API Endpoints của hệ thống: Xác thực & Đăng nhập (`/api/auth`), Sản phẩm (`/api/products`), Đơn hàng (`/api/orders`), Chi nhánh (`/api/branches`), Khuyến mãi (`/api/promotions`), Bản dịch đa ngữ (`/api/translations`), Phân tầng giá (`/api/price-levels`), Nhân sự & Phân quyền (`/api/staff`), Quản lý khách hàng CRM (`/api/customers`).
14. **[PERFORMANCE_AND_CACHING_ARCHITECTURE.md](file:///d:/code/telua_flower/docs/design/PERFORMANCE_AND_CACHING_ARCHITECTURE.md)**: Đặc tả kiến trúc Bộ nhớ đệm 4 tầng (Multi-Layer Caching Architecture): In-Memory RAM Cache, Client Session Cache, Backend `mtime` Cache (<1ms latency), HTTP Cache-Control Headers, Debounced Search và Image Lazy Loading.
