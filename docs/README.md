# Technical Documentation (`telua_flower`)

The `docs/` directory contains all deployment, operational, architecture, design, and requirements reference guides for the project:

1. **[design/MULTI_BRANCH_INVENTORY_TRACKING.md](file:///d:/code/telua_flower/docs/design/MULTI_BRANCH_INVENTORY_TRACKING.md)**: Multi-Branch Real-Time Inventory Tracking & Stock Matrix Design (Traffic light status 🟢/🟠/🔴, Smart Order Routing).
2. **[design/INVENTORY_MANAGEMENT_DESIGN.md](file:///d:/code/telua_flower/docs/design/INVENTORY_MANAGEMENT_DESIGN.md)**: Daily Flower Stock Inbound & Product Quantity Management Design (Daily Quota, Real-time Stock Deduction, Out-of-Stock UX).
3. **[design/AUTHENTICATION_DESIGN.md](file:///d:/code/telua_flower/docs/design/AUTHENTICATION_DESIGN.md)**: Single Login Portal Architecture & Dynamic Role-Based Redirection Design (JWT Structure, Route Guards, API Decorators).
4. **[design/API_ENDPOINTS.md](file:///d:/code/telua_flower/docs/design/API_ENDPOINTS.md)**: Interface API Design & RESTful Endpoint Specifications for Auth, Products, Orders, Branches, Staff, and CRM.
5. **[requirements/PRODUCT_REQUIREMENTS.md](file:///d:/code/telua_flower/docs/requirements/PRODUCT_REQUIREMENTS.md)**: Product Requirements Document (PRD) detailing business goals, customer personas, post-login RBAC permission matrix, and functional specifications.
6. **[requirements/BRANCH_STAFF_MANAGEMENT_GUIDE.md](file:///d:/code/telua_flower/docs/requirements/BRANCH_STAFF_MANAGEMENT_GUIDE.md)**: Step-by-step workflow guide for branch showroom creation, staff onboarding, role assignment, data schema models, and API endpoints.
7. **[DOCKER_UBUNTU_GUIDE.md](file:///d:/code/telua_flower/docs/DOCKER_UBUNTU_GUIDE.md)**: Comprehensive guide for building, running, and testing the application on Ubuntu Linux using Docker and `cli_docker.sh` (zero installation required on Windows).
