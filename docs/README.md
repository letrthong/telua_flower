# Technical Documentation (`telua_flower`)

The `docs/` directory contains all deployment, operational, architecture, and requirements reference guides for the project:

1. **[requirements/PRODUCT_REQUIREMENTS.md](file:///d:/code/telua_flower/docs/requirements/PRODUCT_REQUIREMENTS.md)**: Product Requirements Document (PRD) detailing business goals, customer personas, functional requirements (FR-1 to FR-6), and non-functional requirements (NFR-1 to NFR-3).
2. **[DOCKER_UBUNTU_GUIDE.md](file:///d:/code/telua_flower/docs/DOCKER_UBUNTU_GUIDE.md)**: Comprehensive guide for building, running, and testing the application on Ubuntu Linux using Docker and `cli_docker.sh` (zero installation required on Windows).
