# Technical Documentation (`telua_flower`)

The `docs/` directory contains all deployment, operational, architecture, design, task planning, and requirements reference guides for the project:

1. **[task/README.md](file:///d:/code/telua_flower/docs/task/README.md)**: **Master Implementation Roadmap & 8-Task Coding Plan** (Step-by-step development checklist from Task 01 to Task 08).
2. **[design/JSON_DATA_SCHEMAS.md](file:///d:/code/telua_flower/docs/design/JSON_DATA_SCHEMAS.md)**: Full JSON Data Storage Schemas & Database Entity Relationships (8 JSON models: Branches, Users, Price Levels, Products, Orders, Promotions, Wastage, CRM).
3. **[design/MEMORY_OPTIMIZATION_DESIGN.md](file:///d:/code/telua_flower/docs/design/MEMORY_OPTIMIZATION_DESIGN.md)**: Memory Optimization & Large Data Handling Design (Pagination, Monthly JSON chunking, WebP auto-compression, Streaming I/O, Bounded LRU Cache < 150MB RAM).
4. **[design/OPERATIONAL_EXTENSIONS_DESIGN.md](file:///d:/code/telua_flower/docs/design/OPERATIONAL_EXTENSIONS_DESIGN.md)**: Automated Zalo ZNS / SMS Notifications (with real flower photo link), B2B E-Invoice (VAT) integration, and Thermal Slip / Tag Print Templates (K80 / A5).
5. **[design/PRICE_LEVEL_GOVERNANCE_DESIGN.md](file:///d:/code/telua_flower/docs/design/PRICE_LEVEL_GOVERNANCE_DESIGN.md)**: Price Level Hierarchy & Guardrail Governance Design (Min-Max pricing thresholds, Admin/Manager-only level assignment to prevent pricing errors).
6. **[design/PROMOTION_CAMPAIGN_DESIGN.md](file:///d:/code/telua_flower/docs/design/PROMOTION_CAMPAIGN_DESIGN.md)**: Promotion & Marketing Campaign Management Design (Vouchers, Top Announcement Bar, Hero Banners, 1-Click ON/OFF Switch).
7. **[design/PAYMENT_CANCELLATION_RETURN_DESIGN.md](file:///d:/code/telua_flower/docs/design/PAYMENT_CANCELLATION_RETURN_DESIGN.md)**: Payment Workflows (VietQR, Cards, COD), Order Cancellation Policy (3 Time Tiers), and Return/Exchange/Refund Guarantee (60-Minute Resolution).
8. **[design/PRODUCT_CONTENT_MANAGEMENT_DESIGN.md](file:///d:/code/telua_flower/docs/design/PRODUCT_CONTENT_MANAGEMENT_DESIGN.md)**: Product CMS Design for Staff to add/edit flower prices, upload images, update floral compositions, dimensions, and care tips.
9. **[design/MULTI_BRANCH_INVENTORY_TRACKING.md](file:///d:/code/telua_flower/docs/design/MULTI_BRANCH_INVENTORY_TRACKING.md)**: Multi-Branch Real-Time Inventory Tracking & Stock Matrix Design (Traffic light status 🟢/🟠/🔴, Smart Order Routing).
10. **[design/INVENTORY_MANAGEMENT_DESIGN.md](file:///d:/code/telua_flower/docs/design/INVENTORY_MANAGEMENT_DESIGN.md)**: Daily Flower Stock Inbound & Product Quantity Management Design (Daily Quota, Real-time Stock Deduction, Out-of-Stock UX).
11. **[design/AUTHENTICATION_DESIGN.md](file:///d:/code/telua_flower/docs/design/AUTHENTICATION_DESIGN.md)**: Single Login Portal Architecture & Dynamic Role-Based Redirection Design (JWT Structure, Route Guards, API Decorators).
12. **[design/API_ENDPOINTS.md](file:///d:/code/telua_flower/docs/design/API_ENDPOINTS.md)**: Interface API Design & RESTful Endpoint Specifications for Auth, Products, Orders, Branches, Promotions, Staff, and CRM.
13. **[requirements/PRODUCT_REQUIREMENTS.md](file:///d:/code/telua_flower/docs/requirements/PRODUCT_REQUIREMENTS.md)**: Product Requirements Document (PRD) detailing business goals, customer personas, post-login RBAC permission matrix, and functional specifications (FR-1 to FR-17).
14. **[requirements/BRANCH_STAFF_MANAGEMENT_GUIDE.md](file:///d:/code/telua_flower/docs/requirements/BRANCH_STAFF_MANAGEMENT_GUIDE.md)**: Step-by-step workflow guide for branch showroom creation, staff onboarding, role assignment, data schema models, and API endpoints.
15. **[DOCKER_UBUNTU_GUIDE.md](file:///d:/code/telua_flower/docs/DOCKER_UBUNTU_GUIDE.md)**: Comprehensive guide for building, running, and testing the application on Ubuntu Linux using Docker and `cli_docker.sh` (zero installation required on Windows).
